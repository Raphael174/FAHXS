# Results

Generated outputs belong here or in the configured `runProp.output_root`.

- `legacy_outputs/`: old generated plots and dashboards moved out of `1Dmodel/`.
- New steady/transient runs default to `zip_folders/` through `runProp.output_root`.

Run archives contain numeric `.npz` data, JSON metadata, input snapshots, and optional CSV summaries so plots can be regenerated later.
