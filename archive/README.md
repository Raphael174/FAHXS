# Archive

Non-core files preserved for reference.

- `legacy_solvers/`: older solver variants that should not be used as production entry points.
- `input_presets/`: old copied input-data snapshots.
- `other_work/`: injector and exploratory side work.
- `build_artifacts/`: generated cache/package metadata moved out of the working tree surface.
- `combustion_chemistry.zip`: archived chemistry bundle.

Do not build new workflows on archive files without first promoting the relevant logic back into the maintained package.
