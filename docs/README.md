# Docs

Project documentation and reference material.

- `context/`: concise LLM/Claude/Codex context files.
- `TECHNICAL_REFERENCE.md`: master technical reference for solver physics,
  numerics, materials, assumptions, validation status, and limitations.
- `project_docs/`: design reports, calibration notes, spreadsheets, and figures.
- `solver_design/`: solver design plans and validation scripts.
  - `solver_design/TRANSIENT_CORE_IMPLEMENTATION_PLAN.md`: next-generation
    transient solver plan for transient wall + transient helium coolant with
    quasi-steady hot gas and optional later transient hot gas.
- `reference/`: papers and extracted reference notes.
